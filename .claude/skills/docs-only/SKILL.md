# 문서만 정리할 때

보고는 한국어로 한다. 문서 정리는 커밋·push·PR 초안까지 한 번에 끝낸다("원하시면 커밋할게요"로 끝내지 않는다).

## 순서

1. dev를 최신으로 받고 작업 브랜치를 만든다(예: `docs-phase-N`).
2. `docs/ PHASE_SUMMARY.md`와 `docs/PHASE_COMMITS.md`를 고친다.
   - 빠진 병합·브랜치 정리 기록은 해당 Phase 안에 "병합·브랜치 정리" 항목으로 보완한다.
   - PR 번호, 브랜치 이름, 숫자는 `gh`·`git`으로 확인한 값만 쓴다.
3. 커밋 → push
   - 메시지: `docs: Phase N 작업 완료 사항 정리`
4. PR 초안을 마지막에 쓴다(`merge-flow` 6단계 규칙 그대로: 저장소 밖 `PR_DRAFT.md`, SendUserFile).
5. 이슈가 아직 없다고 안내한다.
   - 사용자가 "이슈 만들고 커밋부터 병합까지 진행해"라고 하면 `merge-flow`를 따른다.
   - 이때 브랜치 이름을 `<이슈번호>-docs-<설명>`으로 바꾸고, 커밋 본문 `Refs #이슈번호`는 새 커밋으로 남긴다(force push 하지 않음).
